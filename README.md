# AI Joke Generator 😂

## Description
AI Joke Generator is a simple desktop application built with Python and CustomTkinter. It uses artificial intelligence to generate funny jokes based on topics entered by the user.

## Features
- Generate jokes using AI.
- Enter any topic you want.
- Simple and user-friendly interface.
- Display generated jokes directly in the application.
- Error handling for API requests.

## Technologies Used
- Python
- CustomTkinter
- OpenAI Python Library
- AI API (Bothub)

## Requirements
Install the required libraries:

```bash
pip install customtkinter openai
```

## Setup
1. Clone or download this repository.
2. Install the required libraries.
3. Get your API key.
4. Add your API key to the `API_KEY` variable.
5. Run the Python file.

## How to Use
1. Open the application.
2. Enter a topic for your joke.
3. Click the **Generate Joke** button.
4. Wait for the AI to generate your joke.
5. Enjoy!
